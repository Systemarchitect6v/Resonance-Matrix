METHOD

What the platform computes

ΔV = V − U

Environmental/observed minus intentional/commanded state.

δ = D(V − U)

Dimensionless normalized differential; D = diag(1/sᵢ).

θ* = θ₀ − δ(δᵀθ₀)/(δᵀδ + ε)

Reference constrained projection when enabled.

e = δ ⊙ θ*

Six component interaction terms retained to expose cancellation.

R = Σeᵢ

Signed scalar constraint residual.

E = ‖e‖₂, G = ‖δ‖₂

Companion magnitude diagnostics.

What it does

  • Evaluates all six aligned rate-state channels in one deterministic update.
  • Makes normalization explicit and user-auditable.
  • Exposes pre-projection and post-projection residual behavior.
  • Supports manual inspection and batch telemetry replay.
  • Exports machine-readable results for independent analysis.

What it does not do

  • It does not infer physical mappings from arbitrary raw sensor units.
  • It does not perform frame transformation or timestamp synchronization for the user.
  • It does not replace an EKF, UKF, complementary filter, or production navigation stack.
  • It does not establish physical validity merely because the algebraic residual is small.
  • It does not claim zero latency, zero drift, or improved accuracy without baseline testing.
